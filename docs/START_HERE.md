# DUALITY 0.3 — начать здесь

Это addon-пакет для установленной **Dota 2 + Dota 2 Workshop Tools**. Самой игры в архиве нет. Код, структура ресурсов и установщик проверены автоматически. Native Panorama и полигон проверены на ПК владельца 2026-11-16; полный боевой playtest ещё продолжается. См. [отчёт](LOCAL_PLAYTEST_2026-11-16.md).

Оставшееся до публичного релиза: [проверяемый список](RELEASE_CHECKLIST.md).

## Самый короткий путь: все герои и способности

1. Распакуйте архив целиком. Закройте Dota и Workshop Tools, если они открыты.
2. Запустите **`START_DEMO.cmd`**. Установщик найдёт Dota через Steam, проверит SHA256 файлов, сохранит резервные копии заменяемых файлов, принудительно пересоберёт весь интерфейс Panorama и текстуру/частицу жёлтых лучей установленным ResourceCompiler и запросит запуск Tools.
3. Если открылось стартовое окно Workshop Tools, выберите addon **duality**. В Console используйте:

```
dota_launch_custom_game duality dota
```

4. Выберите героя на экране Duality. Карточки разделены по основному атрибуту; вкладки физического/магического пути показывают предпросмотр. В обычном матче путь выбирается при первом изучении R на уровне 6. После начала demo полигон включится автоматически: герой 25-го уровня, 25 000 золота, все 11 героев на площадке, вражеская мишень и кнопка **«ПОЛИГОН ГЕРОЕВ»**.
5. В левой панели нажмите портрет нужного героя — им можно управлять. Кнопки **«Базовый / Физическое / Магическое»** создают свежего героя нужного пути, **R · 1/2/3** задают ранг ультимейта. Не нужно перезапускать игру для смены пути. При первом выборе герой и его косметика предварительно загружаются; дождитесь завершения загрузки.
6. Таланты открываются через штатное дерево на уровнях **10/15/20/25** и соответствуют выбранному пути. В полигоне оставлены 4 очка для теста. Scepter даёт только улучшение Duality выбранной ветки; общие Shard Axe/LC/SF подходят обоим путям, остальные Shard дают улучшение Duality; [полная таблица](BRANCH_PROGRESSION.md). При замене героя полигон сбрасывает изученные таланты.
7. **«Вызвать всех 11»** создаёт демонстрационные копии всего ростера с текущим выбранным путём. Копии стоят на месте и не сражаются; их можно осмотреть и выделить. Для управления выбирайте героя портретом в панели полигона.
8. **«Бессмертная / Смертная / Иммунная»** создают вражеские цели перед героем. **«Здоровье / мана / кд»** восстанавливает героя и живые цели. **«Свободные кд»** пополняет ману и снимает перезарядки способностей. **«Убрать копии / цели»** очищает созданные объекты.

Если установщик не нашёл Dota, откройте PowerShell в папке архива:

```powershell
.\START_DEMO.cmd -DotaPath "D:\SteamLibrary\steamapps\common\dota 2 beta"
```

При необходимости можно дополнительно передать `-SteamPath "C:\Program Files (x86)\Steam\steam.exe"`.

В уже установленной копии полигон также включается кнопкой **«ПОЛИГОН ГЕРОЕВ → Войти»** или консольной командой **`rift_lab`**. Требуется один игрок и Tools/cheats. Обычное PvP-лобби не принимает эти команды. Полигон останавливает счёт, события и завершение матча; для возвращения в PvP начните новую сессию.

Резервные консольные команды, если панель ещё компилируется:

```
rift_lab
rift_lab_hero lina magical
rift_lab_hero sf physical
rift_lab_all magical
rift_lab_target mortal
rift_lab_reset
```

Сокращения: `pa`, `ta`, `lc`, `sf`, `cm`, `wr`; остальные — `axe`, `lina`, `juggernaut`, `sven`, `pudge`.

При смене героя/пути/ранга создаётся новый экземпляр: предметы, сборка и накопленные бонусы предыдущего теста не сохраняются. Это позволяет сравнивать способности без остаточных эффектов другого пути.

## Жёлтые лучи статуи LC

У магической Legion Commander статуя выпускает четыре пробивающих луча под углами 90° на каждом из четырёх залпов. Все враги на пути получают магический урон; одна цель учитывается один раз за залп. Каждое попадание по настоящему вражескому герою сокращает кд на 2 секунды, без лимита на залп, до нуля.

Первый луч направлен к ближайшему видимому герою; если рядом никого нет, залп идёт относительно направления LC. Чтобы посмотреть: `rift_lab_hero lc magical`, затем поставить статую кнопкой E.

Цвет задан собственным particle source `content/particles/duality/lc_gold_powershot.vpcf`, а не попыткой перекрасить stock-ресурс через неподдерживаемый control point. Для пересборки только эффектов: **`BUILD_FX.cmd`** (текущий режим запуска сохраняется). Source 2 compiler/render здесь не запускались: визуал требуется проверить в Dota.

## Собственная арена и обычный матч

`START_MATCH.cmd` устанавливает обычный режим, запускает **реальный ResourceCompiler из вашей Dota** и проверяет, что появился актуальный непустой `rift_arena.vmap_c`. Затем запрашивает запуск:

```
dota_launch_custom_game duality rift_arena
```

Только сборка карты, без запуска игры: **`BUILD_MAP.cmd`**.

На арене восемь собственных безопасных баз: внутри нельзя наносить или получать урон, действует быстрое восстановление и сильное развеивание; башня отталкивает вторгшихся врагов. При выходе защита прекращается. По уточнению владельца выровнен только центральный остров; река и внешние высоты сохранены. [Проверки и ограничения](ARENA_REVISION_2026-11-17.md).

В облачном архиве **нет скомпилированной арены**: здесь отсутствуют Source 2 и игровые ресурсы. Если установленный компилятор откажется от исходника Terrain старой версии, установщик покажет ошибку и путь лога. Откройте исходник в Hammer, перестройте Terrain и выполните полную сборку с навигацией по [ARENA_BUILD.md](ARENA_BUILD.md). Демонстрационный режим на штатной карте `dota` от этого шага не зависит.

## Проверка установки и сохранение своих правок

- Установщик меняет только файлы addon `duality`, не удаляет посторонние файлы и не меняет игровые файлы основной Dota.
- Изменённые локальные файлы сохраняются в `<Dota>\duality_backups\duality\<дата-время>\` перед заменой. При существующем junction используйте прежний live-link workflow либо другое имя addon.
- Предварительный просмотр без записи: `powershell -File tools\install_duality.ps1 -DotaPath "..." -WhatIf`.
- Настройка автополигона: `<addon>/scripts/duality_local.kv`, `auto_demo` = `1` для полигона, `0` для обычного матча. Она учитывается только в dev-режиме.
- Lua кешируется: после обновления пакета полностью перезапустите Workshop Tools.
- `build_manifest.json` перечисляет версии/хеши, наличие compiled map и факт отсутствия игрового прогона. SHA256 самого ZIP лежит рядом с архивом.

Ростер: **PA, TA, LC, SF, Axe, Lina, Juggernaut, Crystal Maiden, Windranger, Sven, Pudge**. Все 22 направления реализованы в коде. Финальный баланс, реальный рендер Panorama, nav и поведение API требуют проверки внутри Dota.
