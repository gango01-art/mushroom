# Баланс LC / SF / TA

Единственный источник чисел: `game/scripts/vscripts/rift/data/hero_balance.lua`.
В файле у каждого значения пометка **DR** (DESIGN_REQUIRED, замысел владельца) или **PD** (PLAYTEST_DEFAULT,
стартовое значение для теста) и индекс массива: `[ult]` ранг ульты 1–3, `[q]/[w]/[e]` ранг способности 1–4,
`[ring]` номер кольца SF 1–3, `[shot]` номер выстрела статуи 1–4. Тест `test_hero_data` проверяет длины
массивов и неизменность ключевых DR-значений.

## Защитные решения для FFA (PD, не слова владельца)
- LC physical: выплата за секунду только при попадании чемпиона по цели за последние 2 с; лимит постоянного урона
  100/140/180; поводок 900 от трона с запасом 1 с; победа требует ≥20% max HP цели уроном чемпиона.
  Анти-фид: повторные поединки на ту же цель в окне 90 с умножают награды на 1 / 0.5 / 0.25 / 0.
- LC magical: учитываются только убийства/помощь по настоящим вражеским героям; анти-фид-множитель из scoring;
  Break временно отключает бонус, накопленное сохраняется.
- SF magical: нулевой урон по debuff-immune цели — правило этой ветки DUALITY, не утверждение о стандартной BKB.
- TA magical: +60% интеллекта к урону волн — предложение для spell-сборки.

## Реализованные расчёты (чистая логика)
| Механика | Формула / правило |
|---|---|
| LC полный поединок | 10 выплат × 0.8/1.1/1.4 = 8/11/14 |
| LC победа | итог = 10 × per_second × 1.5 = 12/16.5/21; доплачивается разница с уже выплаченным |
| LC штраф | только при смерти чемпиона: 30% max HP чистым уроном + 1 с стана; взаимная смерть → champion_death |
| LC spell amp | min(cap[r], base[r] + earned); +1 за убийство, +0.5 за помощь (× анти-фид) |
| LC статуя | выстрелы 0.5/3.5/6.5/9.5; −2 с cd за попадание по настоящему вражескому герою; 4 попадания = −8 |
| SF сферы | старт 4; 1 сфера на атаку; восстановление 1.8/1.65/1.5 с, таймер только при свободном слоте; 60% урона атаки без крита |
| SF Shadowraze | +40/60/80% урона атаки физикой, раз на (cast_id, цель), только во время эффекта |
| SF кольца | 300/500/700 на 0.6/1.2/1.8 с, telegraph за 0.4 с, 8 извержений; 1 пакет на (кольцо, цель); immune → 0 урона и 1 fear на каст |
| TA кристалл | 3 прочности; удар TA: сначала импульс, потом −1; враг: −1 без импульса; урон = исходный hit × коэффициент Psi Blades |
| TA волны | урон = база + 0.6 × интеллект (снимок при выпуске); 1 попадание на (волну, цель) |
