# Действующие правила (реализовано в коде)

Исходные требования — `docs/BRIEF.md`. Здесь — решения, принятые при реализации.

## Цикл матча (этап A/B)
- Стадии Dota → наши: CUSTOM_GAME_SETUP→SETUP, HERO_SELECTION→HERO_SELECTION, PRE_GAME→PREPARATION,
  GAME_IN_PROGRESS→ACTIVE. Выбор 40 с, подготовка 10 с, ACTIVE 18:00, overtime ≤ 2:00.
- Время матча = `GameRules:GetGameTime()` + dev-смещение. Пассивный доход — по приросту игрового времени.
  (Предположение: GetGameTime не идёт во время паузы — проверить в OP-003.)
- Команды: по одной на игрока (GOODGUYS, BADGUYS, CUSTOM_1..6). Герои могут повторяться.
- Завершение: `MatchState:finish` идемпотентен; через 3 с вызывается `SetGameWinner(команда победителя)`.

## Очки
- Убийство +3, помощь +1 (≤2), стрик жертвы +1 (3–4) / +2 (5+), потолок 5.
- Помощь: урон post-mitigation (модификатор `modifier_rift_damage_tracker`, OnTakeDamage) за 10 с ≥ 10%
  max HP жертвы на момент смерти; топ-2 по урону, при равенстве — порядок регистрации.
- Окружение/самоубийство: последний вражеский игрок, нанёсший урон за 10 с; иначе никому.
- Урон призывов/иллюзий засчитывается владельцу (GetPlayerOwnerID). Награды — только за смерть
  основного героя игрока (`GetSelectedHeroEntity`), не за иллюзии/клонов/Tempest Double; reincarnation
  не считается смертью.
- Дедупликация: токен `entindex@gametime` на смерть.
- **Ограничение:** вклад только контролем (стан без урона) пока не даёт помощь.

### Анти-фид (решение агента)
Окно 90 с на пару убийца→жертва. Множитель очков, золота и опыта убийцы:

| Повтор в окне | 1-й | 2-й | 3-й | 4-й+ |
|---|---|---|---|---|
| Множитель | 1.0 | 0.5 | 0.25 | 0 |

Очки округляются вниз: 3 → 1 → 0 → 0. Помощь не штрафуется. История пары не сбрасывается
реконнектом (хранится по PlayerID). Отключение — `Config.dev.disable_anti_feed` только в dev.

## Экономика
- Старт: уровень 3 (`HeroLevelUp`), золото ровно 1200 (выставляется при первом появлении, один раз).
- Пассив 10 золота/с, 18 XP/с всем валидным игрокам в ACTIVE/OVERTIME, включая мёртвых и отключившихся.
- Стандартные награды Dota (убийства героев/крипов, тик золота, руны, потеря золота при смерти)
  блокируются фильтрами золота/опыта; все награды матча — кастомные.
- Выкуп выключен, руны выключены, universal shop mode включён.
- Catch-up: выключен (конфиг есть, модуль — позже).

## Возрождение
- Время clamp(6 + floor(t/180), 6, 12). Щит 2 с: −100% входящего урона, снимается своей атакой/кастом.
- Точка: максимум минимального расстояния до живых врагов, штраф 600 за использование < 20 с назад.
