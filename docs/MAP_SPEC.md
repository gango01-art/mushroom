Статус: **не создана**. Код работает и без неё (DEV FALLBACK на карте `dota`).

## Зоны
| Зона | Геометрия | Назначение |
|---|---|---|
| Центр | открытый круг R=900, без препятствий | драка нескольких героев |
| Внутреннее кольцо | R 900–1800, 8 колонн Ø200 на R=1300 под углами 22.5°+k·45° | укрытия, линии видимости |
| Кольцевой маршрут | R 1800–2400, 4 стенки (длина 600, толщина 100) на R=2100 по осям 0/90/180/270°, касательно кругу | путь отхода, есть проходы с обеих сторон каждой стенки |
| Боковые секторы | R 2400–3500, 4 платформы HG высотой +128 на R=2900 под 45/135/225/315°, у каждой 2 пандуса | limited high ground |
| Граница | непроходимая стена/обрыв по квадрату ±3800 | нет недосягаемых безопасных мест |

Требования: ≥2 пути к каждой точке артефакта; нет тупиков с одним входом; от любой точки появления до центра ~2100 units
(≈7 с при скорости 300) — проверить замером в игре (цель 6–10 с до первого столкновения).

## Обязательно для Dota (подтвердить в Hammer)
- По одной точке старта героя на каждую из 8 команд (ожидаемый класс `info_player_start_dota` с параметром команды —
  проверить фактическое имя класса и свойства). Позиции: рядом с rift_spawn_01, 03, 05, 06, 07, 09, 11, 12.
  Код всё равно переносит героя в лучшую точку `rift_spawn_*` при появлении.
- Проходимость (grid nav) должна совпадать с геометрией: стенки, колонны и граница — непроходимы, пандусы — проходимы.
- Освещение: простое ровное, без оформления (этап F).
