## Области, предметы и интерфейс

- Shiva/Gleipnir дают custom AoE 50% своего бонуса, максимум +25% исходного радиуса. Одинаковые предметы не суммируются, backpack исключён. Собственный бонус Sven добавляется отдельно. Предметы не увеличивают число импульсов, урон или длительность.
- Круговые способности используют штатный синий указатель Dota при прицеливании. Убраны дополнительные зелёные круги на курсоре: они дублировали движковый рендер и не совпадали с привязкой к unit target. Для линейных способностей — отдельный коридор ширины; self-area привязана к сущности героя.
- Штатные tooltip Dota: тип, урон, мана/кд, числовые параметры по всем рангам, RU/EN. Данные генерируются из серверного баланса. Перевод с `AbilitySpecial` на `AbilityValues` восстановил числовые строки в текущем клиенте.
- Новый `GameSetup`: восемь FFA-мест, четыре ряда по две карточки, native join/start/cancel, запуск только хозяином. Новый `HeroSelection`: родные портреты, сила/ловкость/интеллект/универсальные, предпросмотр обоих путей, публично подтверждённые пики других игроков.
- Выбор ветки сохранён при первом изучении R на 6-м уровне. Стартовый экран не выбирает ветку: его переключатели — только предпросмотр. Полигон имеет отдельное принудительное переключение путей/рангов.

## Подтверждённые технические причины

1. CM искала цели около выбранной точки, поэтому не выпускала залп во врагов сзади. Теперь каждый залп заново ищет видимых врагов вокруг CM.
2. Native запрос текущего ранга использует `-1`. Старые getters возвращали значения R1; исправлены getters маны/кд оригинальных custom-способностей и общих путей.
3. `GetItemInSlot`/`FindModifierByName` недоступны в клиентском Lua для этого запроса. Сумма AoE предметов реплицируется скрытым модификатором; клиент читает её через `GetModifierStackCount`.
4. Новым linear projectiles нужен явный `fExpireTime`. После исправления native callbacks подтвердили пробитие обеих целей всеми тремя волнами Lina.
5. Source 2 принимал старый формат VPCF `7412167c…` с новыми вложенными float inputs, но мигрировал число испускаемых частиц в **0**. Современный формат `36c3961f…` сохраняет нужные inputs; ResourceInfo подтвердил ненулевой emitter LC. Самодельная волна Sven заменена native эффектом Q по последнему указанию владельца.
6. ResourceCompiler может печатать `ERROR:` при exit code 0 и сохранять output. Установщик теперь отклоняет такой результат. Проверяется и nonzero exit, свежесть, размер, наличие outputs; резервная копия создаётся до перезаписи.
7. Текущий native `Script_GetMagicalArmorValue` принимает inflictor handle; старые API dumps не соответствуют этой сборке. `Log.try` теперь возвращает nil при ошибке, а не строку исключения.

## Фактические проверки в Dota

Промежуточные native прогоны: все 22 пути переключались без вылета. Это не доказывает каждый эффект и каждую комбинацию предметов. На заглушке отдельно проверяются все ранги.

Подтверждены в бою:

- PA: два реальных попадания кинжалов, Desolator debuff на цели; суммарная потеря HP 450/451 в контрольных прогонах.
- CM: четыре залпа наносят урон спереди и сзади (419–432 фактической потери HP на цель в разных прогонах).
- SF: атака даёт 1 душу; койл по двум целям даёт всего 2; добивание не добавляет душ. Круги дали 4 души за два успешных кольца, обе цели получили native stacking debuff.
- LC: Echo Sabre поднимала APS с 1.399 до 4.118; снимок с `GetAttacksPerSecond(true)` остался 1.399, APS воина 1.259 (=90%). LC поднята на 300, смерть воина снимает эффект.
- Lina: три настоящих linear projectiles, каждая вызвала callback по двум мишеням; суммарная потеря HP 588. Врождёнка возвращает 50% burn damage.
- Juggernaut: одна атака при R3 уменьшила кд на 2 с сверх течения времени; магическая буря продолжала наносить урон после смерти. В 100 магических событиях наблюдались обычные и усиленные попадания; урон подтверждён потерей HP, не возвратом ApplyDamage.
- Sven E: два удара и фактический кд 4 с; custom stun 0.75 с стал 0.87 с при +16% длительности. Shiva увеличила фактическую зону попадания Axe с 425 до 462.5.

Владелец 16 ноября подтвердил: души SF при смерти теряются. Его подтверждение относится к обычному игровому тесту; точный процент потери отдельно не измерен. Старый автоматический ForceKill-прогон показывал 10 вместо 7 и остаётся отдельной диагностикой, а не опровержением ручной проверки.

Sven: владелец обнаружил вспышку далеко от героя. ResourceInfo штатного `sven_storm_bolt_projectile_explosion.vpcf_c` подтвердил источник частиц CP3 (`C_INIT_CreateWithinSphere.m_nControlPointNumber=3`). Общий helper задавал только CP0/CP1. Добавлена явная привязка CP3 к месту попадания для физической волны и магических импульсов. Регрессия проверяет обе ветки в координатах (10000, -7000, 500). После полного перезапуска Dota выполнен `rift/dev/sven_visual`: вспышки видны у поражённой мишени рядом со Sven, а не в начале карты. Скриншот: `docs/screenshots/2026-11-16-sven-impact.jpg`. Ускоренные атаки в этом сценарии проверяют визуал, не баланс.
