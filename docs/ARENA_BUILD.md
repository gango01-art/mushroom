# Арена «Расколотый конкорс» — исходник / сборка 0.3

В репозитории есть **исходник Hammer** `content/maps/rift_arena.vmap` (DMX binary 9 / vmap 18), а не готовый `vmap_c`. В облаке карта прочитана и проверена как DMX, но не открывалась и не компилировалась в Workshop Tools. Первая сборка и проверка проходимости обязательны.

[Схема сверху](design/arena-plan.svg).

- Игровой квадрат 7168×7168, границы XY ±3584, поверхность исходного Terrain Z=128.
- 12 симметричных точек появления на R=3000. Система выбирает безопасную, а не закреплённую за командой.
- 8 стартов команд 2, 3, 6–11. Один игрок на команду, как в существующем FFA.
- Открытый центр R=900; четыре точки Сердца на R=1500.
- Восемь коротких групп деревьев дают разрушаемые укрытия. Вокруг каждой есть обход с двух сторон.
- Четыре штатных shop-prefab в диагональных секторах ±2304. Universal shop mode открывает ассортимент у этих магазинов; покупки из любой точки не реализованы.
- Высокий внешний Terrain образует край. Сервер дополнительно возвращает вышедшего за границу героя внутрь. Guard не подменяет коллизии или навигацию.
- Башен, Ancient, линий и спавнеров крипов в авторском наборе сущностей нет. Расположение не является реализацией всех платформ из старой graybox-спецификации: high ground и пандусы отложены до проверки базовой навигации.

## Автоматизированная попытка сборки

`BUILD_MAP.cmd` устанавливает исходники с backup и вызывает ResourceCompiler из `game/bin/win64` установленной Dota. Проверяются exit code и актуальный непустой map output. `START_MATCH.cmd` дополнительно запрашивает запуск через Steam. Если compiler сообщает, что Terrain требует обновления/пересчёта, выполните первую сборку в Hammer ниже. Самостоятельно скачивать сторонние компиляторы не нужно.

Для быстрого просмотра всех героев предусмотрен `START_DEMO.cmd` на штатной карте `dota`: этот режим не зависит от компиляции `rift_arena`. [Запуск полигона](START_HERE.md).

## Первая сборка на Windows

1. Скопировать `game/` и `content/` в addon `duality` через `tools/sync_addon.ps1`.
2. В Workshop Tools открыть **Hammer → `content/dota_addons/duality/maps/rift_arena.vmap`**.
3. При предложении обновить старый формат карты сохранить обновлённую копию в addon.
4. Перестроить Terrain tiles и сохранить: исходник меняет высоты и размещение объектов программно, старые рассчитанные tile-конфигурации шаблона требуют пересчёта. Проверить в окне Hammer, что край и деревья действительно появились.
5. Выполнить полную сборку карты через F9, включая навигацию. Убедиться, что текущая версия Tools разрешает `maps/tilesets/radiant_basic.vmap` и `maps/prefabs/shop_blacksmith_radiant.vmap`. Это штатные пути из шаблона BMD, не проверенные в установленном клиенте владельца.
6. После изменения Lua полностью закрыть и заново открыть Workshop Tools. В консоли:

```
dota_launch_custom_game duality rift_arena
rift_map_check
rift_status
```

Ожидается `[RIFT][INFO][MAP] contract OK: 12 spawns, 4 relic points, center, bounds`; предупреждения о временных точках появления в HUD быть не должно. Обойти каждый магазин, центр, 12 спавнов и четыре точки Сердца. Проверить спавн каждой команды и выход за границу Blink/Force Staff.

Если сборка карты ещё не выполнена, `dota_launch_custom_game duality dota` остаётся режимом проверки механик с DEV FALLBACK. Стандартная карта **не доказывает** работоспособность новой арены.

## Воспроизводимость исходника

`tools/build_arena.py` создаёт исходник и `rift_arena.layout.json`. Требуется Python 3 и оригинальный `template_map.vmap`:

- источник: `https://github.com/bmddota/barebones`, commit `873bcb971c127a9babd36afb3f27d6aeeb20d25f`;
- файл: `content/dota_addons/barebones/maps/template_map.vmap`;
- SHA-256: `3c4df9cb9bdf15e95728c71d190d332e78cf02314687db1b6b666e15d939499f`.

```
python3 tools/build_arena.py --template /path/to/template_map.vmap
python3 tools/check_arena.py
python3 tools/draw_arena.py
```

Генератор перезаписывает **исходник** карты; не запускать поверх ручных правок Hammer без их сохранения. В репозитории уже лежит результат, загрузка шаблона для обычной сборки/игры не нужна.

DMX-адаптер включён в `tools/vendor/datamodel.py` (MIT). Это только инструмент разработки, не часть VScript. Происхождение и лицензии: [THIRD_PARTY.md](THIRD_PARTY.md).
