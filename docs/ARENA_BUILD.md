# Арена Duality — The Verdant Reach

Основа выбрана после реального осмотра [Desert Duo и Forest Solo](ARENA_COMPARISON_2026-11-17.md): **Valve Overthrow / Forest Solo**. Оригинал Overthrow сохранён. Прежний восьмиугольный прототип заменён.

- Размер 11264×11264 (XY ±5632), прежняя сетка 64×64. Внешние native высоты, река, подходы, деревья и перекрытия обзора сохранены. Только внутренний остров выровнен до Z=128; изменены 185 вершин высоты, все они ближе 1950 единиц к центру. Вода не менялась. Это большая арена, не уменьшенная копия старого полигона.
- Восемь команд по одному игроку, восемь фиксированных собственных баз, 12 резервных точек появления, четыре точки существующего артефакта, десять нейтральных магазинов. Десять внешних карманов сохранены как геометрия. На настоящей арене первый спавн и возрождение используют собственную базу; быстрый полигон на карте dota сохраняет прежний выбор точки.
- Удалены старые башни/фонтаны, XP-юниты, трон, сундуки, логотипы/баннеры и игровые частицы Overthrow. Механика Duality остаётся своей. Собственные новые power-runes не вводились.
- Из центра удалён невидимый solid с материалом toolsskip и старые лестничные модели внутреннего плато. Внешние склоны и переходы не выравнивались. Большой вариант выравнивания R=3840 отвергнут владельцем и восстановлен из резервной копии до этой локальной правки.
- Миникарта 512×512 экспортирована самим движком командой `dota_minimap_create`; после перезагрузки карты отображается в HUD. Схема из исходных terrain data: [arena-plan.svg](design/arena-plan.svg).

Текущая локальная правка и реальные проверки: [ARENA_REVISION_2026-11-17](ARENA_REVISION_2026-11-17.md). Ниже сохранены исходные измерения первой сборки для истории.

## Исходная сборка до изменения центра

ResourceCompiler создал `maps/rift_arena.vpk`, world physics и gridnav: **304 compiled, 0 failed**. Текущие Tools выпускают VPK, отдельного `vmap_c` нет. После полного перезапуска карта загрузилась с интерфейсом Duality, выбором героя и лабораторией. Native выборка адаптации: **24/24** (12 спавнов, 8 стартов, 4 артефакта) от проходимого центрального пола. Исходный marker в центре непроходим; это явно отражено в логе. Реальное движение и границы его проверки — в TEST_RESULTS.

Установщик сохраняет backups перед заменой и перед сборкой ресурсов, проверяет exit code, ERROR/FATAL и Write … Failed! в логе (последнее встречается даже с exit code 0 при заблокированном Dota VPK) и наличие свежего непустого output. План Match/BuildMap включает **22 outputs**: 14 Panorama, 6 VFX/текстур, material миникарты и map VPK. Отдельный BuildAssets — 21 без карты. Mock проверки установщика: 191 на PowerShell 5.1 и 7; mock не доказывает работу Source 2.

## Запуск

Закрыть Dota/Tools и запустить `START_MATCH.cmd` либо `BUILD_MAP.cmd`. Для явного запуска в Tools:

```
dota_launch_custom_game duality rift_arena
```

`START_DEMO.cmd` сохраняет быстрый полигон на штатной карте `dota`. При dev-установке лаборатория может включиться и на арене; одиночная лаборатория не является PvP-проверкой.

## Дальнейшее редактирование

1. Через штатный Create Addon сделать копию Valve Overthrow (здесь `duality_map_review`). Открыть `forest_solo`, сохранить **отдельно** нынешним Hammer как vmap 40+, например `forest_duality_base.vmap`.
2. Перед генерацией сохранить backup текущего `rift_arena.vmap`: генератор заменяет его, ручные правки потеряются без backup.
3. Выполнить `python tools/build_arena.py --template path/to/forest_duality_base.vmap`, затем `python tools/draw_arena.py`. Генератор сохраняет контрольный digest высот/воды/путей/деревьев/gridnav; геометрия не масштабируется. Разрешено выравнивание только центрального острова до уровня окружающего сухого пола, без изменения реки/внешней части. Контрольный digest вне R=2304 закреплён от исходной версии, а не вычисляется заново как новый эталон.
4. Собрать и загрузить карту. Выполнить `dota_minimap_create`, скопировать созданные `content/materials/overviews/rift_arena.{tga,txt,vmat}` и `game/resource/overviews/rift_arena.txt` в проект. Выполнить `python tools/build_arena.py --stamp-overview`; команда фиксирует digest, но сама не запускает экспорт.
5. `python tools/check_arena.py`, полный `tools/check.sh`, затем новая native компиляция и проверка в Dota. Смена геометрии требует нового экспорта миникарты.

Native dev-команды: `script_reload_code rift/dev/arena_probe` (24 точки) и `script_reload_code rift/dev/arena_walk` (три маршрута движения). Обе требуют одиночный Tools/lab. Не заменяют обход каждого уступа, проверку магазина и Blink/Force Staff у границы.

В DMX-адаптере исправлен повторный цикл пустых строк: ранее они превращались в null, затем в element другого типа. `tools/check_dmx.py` проверяет три цикла и UInt8/UInt64. Не использовать старые vmap 18/20 как вход генератора; сначала сохранить копию нынешним Hammer.

Происхождение Valve/Barebones/DMX и лицензии вспомогательных материалов — [THIRD_PARTY.md](THIRD_PARTY.md). Workshop-публикация не выполнялась.
