# Контракт карты

Проверяется при старте (`rift/engine/map_contract.lua`) и командой `rift_map_check`.
Каждое отсутствующее имя пишется в лог (`[RIFT][ERROR][MAP] missing entity <имя>`; в dev — WARN).

| Имя | Кол-во | Назначение |
|---|---|---|
| `rift_spawn_01` … `rift_spawn_12` | 12 | точки появления по внешней части |
| `rift_relic_01` … `rift_relic_04` | 4 | точки появления артефакта |
| `rift_center` | 1 | центр арены |
| `rift_bounds_min`, `rift_bounds_max` | 2 | углы технической границы (XY) |

Класс сущности — точечная сущность с именем (targetname), например `info_target`; класс подтвердить
в текущем Hammer (задание оператору на этапе D). Код ищет только по имени (`Entities:FindByName`).
Без 12 точек появления включается DEV FALLBACK (кольцо R=2400 вокруг 0,0) и HUD показывает предупреждение.
