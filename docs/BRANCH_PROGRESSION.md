# DUALITY — таланты и Aghanim по веткам

Сгенерировано из `hero_balance.lua`. Числа — первый баланс для playtest. Выбор пути остаётся при первом изучении R на уровне 6. Таланты используют штатные уровни 10/15/20/25 и очки способностей.

Scepter и Shard дают дополнительные эффекты выбранной ветки. Штатные улучшения обычных навыков Dota сохраняются. Бонусы области ограничены +20% исходного радиуса/полуширины; дополнительные импульсы суммарно ограничены двумя. Процентное сокращение кд пути ограничено 35%; плоские улучшения сборки применяются отдельно.

## axe

| Уровень | Физическая ветка (два выбора) | Магическая ветка (два выбора) |
|---|---|---|
| 10 | +20 урона атаки **или** +200 здоровья | +2 маны/сек **или** +200 здоровья |
| 15 | +25 скорости атаки **или** +20 скорости передвижения | +6 % усиления заклинаний **или** +100 дальности заклинаний |
| 20 | +40 радиуса / полуширины **или** +10 % сокращения кд навыка пути | +40 радиуса / полуширины **или** +10 % сокращения кд навыка пути |
| 25 | +25 % урона навыка пути **или** +100 дальности притягивания R | +20 % урона навыка пути **или** +1 импульсов / залпов |

Физическая: **Scepter** — +20 % урона навыка пути; +60 радиуса / полуширины; **Shard** — +10 % сокращения кд навыка пути.

Магическая: **Scepter** — +50 радиуса / полуширины; +1 импульсов / залпов; **Shard** — +10 % сокращения кд навыка пути.
