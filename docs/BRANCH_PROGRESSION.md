# DUALITY — таланты и Aghanim по веткам

Сгенерировано из `hero_balance.lua`. Числа — совместный баланс веток, талантов и Aghanim для playtest. Выбор пути остаётся при первом изучении R на уровне 6. Таланты используют штатные уровни 10/15/20/25 и очки способностей.

Scepter и Shard дают дополнительные эффекты выбранной ветки. Штатные улучшения обычных навыков Dota сохраняются. Бонусы области ограничены +20% исходного радиуса/полуширины; дополнительные импульсы суммарно ограничены двумя. Плоские и процентные сокращения кд от сборки, талантов и Aghanim вместе ограничены 25% исходного кд. Штатное сокращение кд от предметов Dota применяется движком после этого; возвраты за попадания считаются отдельно.

| 20 | +40 радиуса / полуширины **или** +10 % сокращения кд навыка пути | +40 радиуса / полуширины **или** +10 % сокращения кд навыка пути |
| 25 | +15 % урона навыка пути **или** +100 дальности притягивания R | +12 % урона навыка пути **или** +1 импульсов / залпов |

Физическая: **Scepter** — +15 % урона навыка пути; +60 радиуса / полуширины; **Shard** — +10 % сокращения кд навыка пути.

Магическая: **Scepter** — +50 радиуса / полуширины; +1 импульсов / залпов; **Shard** — +10 % сокращения кд навыка пути.
