# Только DUALITY Aghanim и врождёнка TA

Проверка на ПК владельца: Windows, Dota 2 Workshop Tools, addon `duality`, карта `rift_arena`, одиночный lab. Это не полный PvP playtest.

## Подтверждённая причина

Предыдущая система намеренно добавляла бонусы ветки поверх настоящих native Scepter/Shard. Поэтому интерфейс показывал Psionic Projection и другие штатные улучшения, а `HasScepter()` позволял C++-способностям применять их. Это было сочетание двух систем, а не доказанная проблема старых скомпилированных ресурсов.

По уточнению владельца Scepter теперь включает только DUALITY. Сохранены общие Shard Axe/LC/SF, подходящие обеим веткам; прежние дополнительные бонусы Shard этих трёх героев удалены. Остальные Shard включают только DUALITY. Выбор пути по-прежнему при первом R на уровне 6.

## Изменения

- Те же магазинные ID и рецепты Scepter/Blessing/Shard, но Lua-предметы и отдельное владение DUALITY. Native `HasScepter()` остаётся false. Scepter даёт +10 ко всем атрибутам, +175 здоровья/маны; Blessing сохраняет улучшение без этих характеристик. Shard/Blessing автоматически поглощаются, повторный экземпляр не уничтожается впустую. Рюкзак/тайник и дубликаты покрыты логическими тестами; полный native цикл покупки/переноса/продажи остаётся в release checklist.
- В Native Shard ownership допускаются только Axe, LC и SF. Другие герои не получают старые улучшения. Метаданные native улучшений очищаются и в общей KV, и в per-hero AbilityDefinitions; описания и таблица генерируются из баланса.
- Подсказка значков отражает осматриваемого героя, путь и подтверждённое сервером владение. Используются ровно два штатных прозрачных силуэта с on/off-текстурами Dota; дополнительные предметные картинки и чёрная подложка удалены. Старые накладки очищаются и при обновлении уже открытого HUD.
- Врождёнка TA использует прежнюю кривую восстановления по уровню: после 0.2 с без урона начинается накопление, затем достигается максимум. Движение, атаки и способности не прерывают эффект; положительный полученный урон сбрасывает его. Break временно выключает восстановление. На уровне 25 максимум +9.9 HP/sec и +7 mana/sec. Meld остаётся отдельной способностью.

## Фактически выполнено в Dota

2. TA двигалась после сброса врождёнки: накопление достигло 100%, измерено 9.9/7. Применён реальный чистый урон: stack сразу 0. В первом прогоне найден клиентский вызов серверного `IsAlive`; исправлен и покрыт тестом клиента без этого API. Повторная чистая сессия завершилась без прежней Lua-ошибки.

## Границы

Не проверены все эффекты всех Aghanim в реальном PvP, все комбинации талантов/предметов, иммунитеты/развеивание, смерть/переподключение и полный магазинный цикл. Боевой тест LC подтверждает барьер для заданного урона, не его поведение против каждого типа атаки. Для SF измерены попадания/кд и значение slow, не скорость передвижения каждой цели. В установленной Dota также отсутствуют штатные токены `DOTA_Tooltip_CurrentStats_Header` и `templar_assassin_refraction_SummaryDescription`; предупреждения при hover обычной Refraction записаны отдельно и не объявляются устранёнными. Во время замен остаются native предупреждения косметики об отсутствующем `attach_hitloc`; это не объявляется исправленным. Общий остаток до релиза — [RELEASE_CHECKLIST](RELEASE_CHECKLIST.md).
