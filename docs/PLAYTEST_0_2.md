# Передача в чат игрового тестирования — DUALITY 0.2

## Контекст для следующего агента

Продолжить проверку DUALITY в реальном Dota 2 Workshop Tools на машине владельца. Исходники готовы к игровому прогону, **играбельность и баланс в Dota ещё не подтверждены**. Не менять существующие требования LC/SF/TA без причины. Не публиковать в Workshop. `index.html` относится к старому проекту и не менялся.

Ростер: PA, TA, LC, SF + **Axe, Lina, Juggernaut, Crystal Maiden, Windranger, Sven, Pudge**. Всего **11 героев / 22 пути**, до 8 игроков в FFA. Четыре старых героя сохранены. Новые 14 путей реализованы общим серверным исполнителем; их реальные API-вызовы, частицы и ощущения в игре требуют проверки.

## Обновление и карта

1. Получить ветку разработки с этим изменением. Не тестировать старый `main` и не смешивать версии файлов.
2. Сначала предварительный просмотр копирования, затем копирование:

```
powershell -ExecutionPolicy Bypass -File tools\sync_addon.ps1 -WhatIf
powershell -ExecutionPolicy Bypass -File tools\sync_addon.ps1
```

Скрипт не удаляет и не перезаписывает более новые локальные файлы addon. Если что-то пропущено, разобраться с различиями; не затирать правки владельца. Проверить в Console версию BOOT **0.2.0-alpha**.
3. Собрать `rift_arena.vmap` по [ARENA_BUILD.md](ARENA_BUILD.md). `vmap_c` не поставляется.
4. Полностью перезапустить Workshop Tools, затем `dota_launch_custom_game duality rift_arena`. Только повторный `dota_launch_custom_game` не очищает кеш `require`.

## Минимальный приёмочный прогон

| Проверка | Что должно происходить |
|---|---|
| Загрузка | BOOT 0.2.0-alpha, MAP contract OK, без Lua stack trace и missing modifier |
| Выбор героя | Все 11 доступны в стандартном выборе. Путеводитель — справочник, не отдельный выбор героя |
| Ранний матч | Уровень 3, 1200 золота, таймер боя 18:00. Путеводитель автоматически закрывается к бою и при предложении улучшения |
| Верхняя панель | До восьми портретов по стабильным слотам; счёт/места обновляются; ваш портрет выделен. После смерти — число секунд, после возрождения — обычный портрет |
| Меню | Кнопка «Путеводитель», 11 героев, обе ветки каждого, закрытие. Не мешает способностям, минимaпе и магазину |
| Улучшения | Карточки справа, сворачивание/возврат; двойной клик не выдаёт два улучшения |
| Выбор пути | Довести героя до 6-го уровня, **вложить очко в R**, затем выбрать путь. Ульта остаётся на R, уровень/оставшаяся перезарядка перенесены; Q/W/E не потеряны |
| Таймаут | В отдельной сессии не выбирать 45 секунд: применяется физический путь ровно один раз |
| Магазины | Купить предмет у каждого из 4 магазинов, проверить попадание в инвентарь, расход золота и доступ разных FFA-команд |
| Карта | Все точки спавна доступны, не в деревьях/обрывах; два обхода у укрытий; край не позволяет уйти в безопасную недоступную область |
| Сердце | `rift_skip 180` приближает событие по логическим часам. Подбор, перенос, смерть/дроп, очки и следующий event timer |
| Финал | `rift_skip 1080`; проверить победителя/ничью/овертайм и таблицу результатов. Отложенные эффекты новых путей не наносят урон после FINISHED |
| Переподключение | Восстанавливаются путь, сборка, публичный HUD и приватные предложения |

Проверить 1920×1080 и 2560×1440 (и используемое владельцем разрешение). Панель не должна перекрывать нижние способности и предметы. Браузерный макет в `docs/design/` — только дизайн с заглушками портретов; он не проверяет CSS/рендер Source 2.

## Новые пути: сценарии

Каждый путь проверять в **новой сессии**: выбор постоянный на матч. `rift_force_direction <id>` допустим только как dev-сокращение после вложенного очка в ульту; не подменяет тест обычного меню. ID ниже.

| Герой | Physical ID / проверка | Magical ID / проверка |
|---|---|---|
| Axe | `rift_axe_physical`: физический основной удар + ослабленное рассечение; сильнее по раненой цели; убийство настоящего героя сокращает остаток кд наполовину, иллюзия — нет | `rift_axe_magical`: фиксированная зона, 6 импульсов, замедление; лечение от героев ограничено на импульс суммарно |
| Lina | `rift_lina_physical`: 3 узких луча, фиксированное направление; цель сбоку/за спиной не получает урон | `rift_lina_magical`: задержка 0.9, 3 расширяющихся импульса; выход из области спасает |
| Juggernaut | `rift_juggernaut_physical`: 5 ударов/прыжков только по видимым врагам внутри исходной зоны; нет неуязвимости; stun/disarm останавливают серию | `rift_juggernaut_magical`: 10 магических импульсов следуют за героем; можно атаковать/кастовать; смерть прекращает эффект |
| Crystal Maiden | `rift_cm_physical`: +140 дальности, каждый 3-й попавший удар по герою вызывает физический взрыв и короткое оцепенение; стойка развеивается | `rift_cm_magical`: 8 импульсов расширяющейся зоны; каждый 3-й накладывает короткое оцепенение; не channel |
| Windranger | `rift_wr_physical`: каждый 2-й попавший удар выпускает физическую линию через цель; проверить несколько целей на линии | `rift_wr_magical`: 3 магические волны по одной линии; больше урона на её дальнем конце, без автонаведения |
| Sven | `rift_sven_physical`: каждый 3-й удар вызывает физический удар по площади; стандартный God Strength не остаётся скрытым активным усилением | `rift_sven_magical`: 4 импульса на землю; оглушает только первый, остальные только наносят урон |
| Pudge | `rift_pudge_physical`: 6 физических тиков; враг и Pudge могут действовать; расстояние >575 разрывает связь навсегда | `rift_pudge_magical`: 7 нарастающих магических импульсов; лечение только пока Pudge внутри поля, общий лимит за импульс |

Для каждой ветки: BKB/debuff immunity, Linken для целевых R, иллюзии, смерть/удаление цели, смерть владельца, dispel замедления/корней/стойки. Физические дополнительные попадания — **spell damage**, не атаки: не должны вызывать item procs, crit, attack lifesteal или рекурсивное cleave. Обычные атаки и базовые Q/W/E сохраняются.

Эффекты/звуки — штатные ресурсы Dota, precache добавлен. Внешний вид и CP-контролы частиц, shop-prefab и современная Terrain-конверсия не проверены клиентом: зафиксировать missing resource и визуальные проблемы отдельно от логических.

Старые непроверенные задачи OP-016/017 и OP-025…029 остаются актуальны. Новые 14 веток не означают, что старые LC/SF уже прошли игровой прогон.
