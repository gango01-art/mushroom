DUALITY — ПОЛИГОН ГЕРОЕВ

1. Нужны установленная Dota 2 и DLC Dota 2 Workshop Tools.
2. Распакуйте архив целиком, закройте Dota/Workshop Tools.
3. Запустите START_DEMO.cmd.
4. Если открылся выбор addon в Tools: выберите duality, затем в Console:
   dota_launch_custom_game duality dota
5. Выберите любого героя. После начала матча автоматически откроется полигон.

В панели «ПОЛИГОН ГЕРОЕВ»:
- портрет — создать управляемого героя;
- Базовый / Физическое / Магическое — переключить путь;
- R · 1/2/3 — ранг ультимейта;
- Вызвать всех 11 — показать весь ростер выбранного пути;
- Мишени, восстановление здоровья/маны/кд, свободные кд.

Резервные консольные команды:
  rift_lab
  rift_lab_hero lina magical
  rift_lab_all physical
  rift_lab_target mortal
  rift_lab_reset

Статуя магической LC выпускает четыре жёлтых пробивающих луча.
Каждое попадание по настоящему герою сокращает кд на 2 секунды до нуля.
START_DEMO компилирует эффект установленным ResourceCompiler.
Только эффекты: BUILD_FX.cmd.

Собственная арена: BUILD_MAP.cmd либо START_MATCH.cmd.
В ZIP исходник арены; её скомпилирует ResourceCompiler из ваших Workshop Tools.
При ошибке Terrain требуется первая полная сборка в Hammer. Полигон на
штатной карте dota доступен независимо от компиляции новой арены.

Полная инструкция: docs/START_HERE.md.
Установщик сохраняет резервные копии заменяемых файлов и не удаляет ваши
посторонние файлы addon. Обычный матч не допускает команд полигона.

В облаке пройдены программные проверки. Реальный запуск Dota и компиляция
Source 2 на компьютере владельца ещё не проверены.
